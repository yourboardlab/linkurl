# 시작페이지 사용법

- 파일: [linkurl/index.html](linkurl/index.html)
- 검색창에 검색어를 입력하거나 URL을 붙여넣고 Enter를 누르면 이동합니다.
- 그룹/바로가기는 "새 그룹", "+ 바로가기" 버튼으로 추가하고, 카드나 그룹 왼쪽의 ⠿ 손잡이를 드래그해 순서를 바꾸거나 다른 그룹으로 옮길 수 있습니다.
- "내보내기" / "불러오기" 버튼으로 텍스트 형식(`# 그룹명` + `이름 - URL : 설명`)으로 백업하거나 다른 곳에 붙여넣을 수 있습니다.

## 여러 크롬 프로필(구글 계정) 간 자동 동기화

같은 컴퓨터의 서로 다른 크롬 프로필에서 이 페이지를 열면서 데이터를 계속 같은 상태로 맞추고 싶다면, 파일을 직접 여는 대신 아래처럼 로컬 서버를 통해 열어주세요.

1. [run-server.bat](linkurl/run-server.bat)을 더블클릭해서 실행합니다. (Node.js가 설치되어 있어야 합니다) 이 창은 켜둔 채로 두세요.
2. 두 크롬 프로필 모두에서 `file://...` 대신 **http://localhost:8787** 주소로 접속합니다.
3. 한쪽에서 그룹/바로가기를 추가·수정·삭제·순서변경하면 즉시 [linkurl/data.json](linkurl/data.json) 파일에 저장되고, 다른 프로필에서는 새로고침하거나 그 탭으로 돌아오기만 해도(창 전환 시 자동 확인) 최신 상태로 반영됩니다.

서버를 실행하지 않고 `index.html`을 그냥 더블클릭해서 열면, 예전처럼 그 브라우저의 `localStorage`에만 저장되는 독립 모드로 동작합니다 (서버가 없을 때 자동으로 이 모드로 전환됨).

- "초기화" 버튼으로 저장된 바로가기를 초기화할 수 있습니다.
